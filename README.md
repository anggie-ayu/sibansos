# SiBansos – Sistem Pendataan, Scoring & Bansos

SiBansos merupakan aplikasi berbasis web yang dirancang untuk membantu proses pendataan, pengelolaan, verifikasi, dan penilaian kelayakan keluarga sebagai calon penerima bantuan sosial. Aplikasi ini mengelola data keluarga dan indikator kondisi sosial ekonomi yang digunakan dalam proses scoring untuk membantu menentukan tingkat kelayakan dan prioritas penerima bantuan sosial.

Aplikasi SiBansos memiliki beberapa fitur utama, yaitu login dan registrasi, dashboard, pengelolaan data keluarga, scoring kelayakan bantuan sosial, verifikasi data, deteksi anomali, dan profil pengguna.

## Fitur Utama
- Login dan Registrasi
  Digunakan untuk mengelola akses pengguna ke dalam sistem.
- Dashboard
  Menampilkan ringkasan dan informasi terkait data keluarga serta proses pendataan bantuan sosial.
- Data Keluarga
  Mengelola data kepala keluarga dan anggota keluarga beserta informasi sosial ekonomi yang diperlukan.
- Scoring Kelayakan
  Menghitung skor berdasarkan indikator kondisi sosial ekonomi keluarga untuk menentukan tingkat kelayakan penerima bantuan sosial.
- Verifikasi Data
  Membantu proses pemeriksaan dan validasi data keluarga sebelum digunakan dalam proses penentuan penerima bantuan.
- Deteksi Anomali
  Membantu mengidentifikasi data yang memiliki ketidaksesuaian atau perlu diperiksa lebih lanjut.
- Profil Pengguna
  Menampilkan informasi pengguna yang sedang menggunakan sistem.
